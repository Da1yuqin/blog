# Day / Journal

随笔、旅行记录和项目复盘：[阅读博客](https://da1yuqin.github.io/blog/)。

```sh
bundle install
bundle exec jekyll serve
```

本地访问 `http://127.0.0.1:4000/blog/`。`_posts/` 保存文章完整 Markdown 正文，`images/` 保存公开图片。新增或修改文章后推送到 GitHub，GitHub Pages 自动生成文章列表、正文和 RSS，无需正文服务或邀请码。未发表内容保存在本公开仓库之外。

评论继续使用既有服务，旧留言地址保持不变；评论服务不可用时不影响文章阅读。
